# Security boundaries

This is an inert synthetic ZIP metadata learning lab, not an extraction service
or malware sandbox. Do not interpret a complete report as permission to extract.
Payloads, CRC, local-header agreement and extraction behavior are unverified.
Real hostile samples require a separately approved isolated environment.

Report defects privately to the repository owner through an available private
channel. No public reporting endpoint is configured in this local-only stage.
Include a small inert reproduction and expected/observed metadata outcome; do
not submit secrets, customer archives, executable payloads or decompression bombs.

Runtime is standard-library-only. Development dependencies and pinned Actions
still require supply-chain review and updates. Hosted CodeQL/secret scanning
eligibility and branch protections have not been verified.
